# 🤖 น้องทานตะวัน-Bot · หุ่นยนต์แนะนำข้อมูลวิทยาลัยเทคนิคท่าหลวงซิเมนต์ไทยอนุสรณ์

หุ่นยนต์ **"กล่องพูดได้"** สำหรับตั้งที่วิทยาลัย ให้ผู้มาติดต่อ **พูดถามข้อมูลแล้วได้คำตอบเป็นเสียงภาษาไทย** — เรื่องหลักสูตร การรับสมัคร การติดต่อ และอื่นๆ

> 🎯 **หัวใจของระบบ:** ตอบจากฐานข้อมูลวิทยาลัยเท่านั้น **ไม่ตอบมั่ว** — ถ้าไม่มีข้อมูล จะบอกให้ติดต่อเจ้าหน้าที่ (โทร 0-3628-1295)

- 🕐 **นาฬิกา + วันที่ไทย + อากาศท่าหลวง** (Open-Meteo ฟรี อัปเดตทุก 30 นาที — เน็ตหลุดซ่อนการ์ดอากาศเอง)

### 🔧 ชิ้นส่วน

| ชิ้นส่วน | หน้าที่ |

### 🎬 การใช้งานจริง

1. **เสียบปลั๊ก** → Pi เปิดเอง ขึ้นหน้าจอเอง ไม่ต้องมีคนมากด
2. คนเดินมา **กดปุ่ม** แล้วพูด *"วิทยาลัยมีสาขาอะไรบ้าง"*
3. **ตาหุ่นเปลี่ยน** เป็นท่าฟัง → ท่าคิด
4. หุ่น **พูดตอบด้วยเสียงผู้ชาย** + จอตัวขึ้นคำตอบเป็นตัวหนังสือ
5. ถามทาง เช่น *"โรงอาหารอยู่ไหน"* → **ขึ้นแผนที่** ด้วย
6. ถามเรื่องที่ไม่มีข้อมูล → **บอกให้ติดต่อเจ้าหน้าที่** ไม่แต่งเอง
7. **ยื่น QR** (เช่น ที่ติดหน้าห้อง) ให้เครื่องสแกน → หุ่นพูดข้อมูลของจุดนั้นทันที

### 🧠 Raspberry Pi คืออะไร ทำไมต้องใช้

**Raspberry Pi = คอมพิวเตอร์จิ๋วขนาดบัตรเครดิต** ทำหน้าที่เป็นสมองของหุ่น — ตอนทดสอบเรารันโปรแกรมบนโน้ตบุ๊ก ส่วน Pi คือ "คอมจิ๋วที่มาทำงานแทนโน้ตบุ๊ก" แล้วซ่อนไว้ในกล่อง

| งาน | ใครทำ |
|---|---|
| รันโปรแกรมหุ่น (`server.py`) | Pi |
| ส่งคำถามไปถาม AI ผ่าน WiFi | Pi |
| ส่งภาพออกจอ touch + จอใบหน้า | Pi |
| รับเสียงจากไมค์ / ส่งเสียงออกลำโพง | Pi |
| รับสัญญาณจากปุ่มกดจริง | Pi |

→ **จอ ไมค์ ลำโพง ปุ่ม — ทุกอย่างเสียบเข้า Pi** Pi คือศูนย์กลาง

**ทำไมไม่ใช้โน้ตบุ๊ก?** ใช้ได้ แต่ Pi เหมาะกว่าเพราะ
- **เล็ก** ซ่อนในกล่องได้ ดูเป็นหุ่นยนต์ ไม่ใช่โน้ตบุ๊กวางอยู่
- **ถูก** ~2,000 ฿ เทียบกับโน้ตบุ๊กเป็นหมื่น
- **เปิดเองอัตโนมัติ** เสียบปลั๊ก → หุ่นพร้อมใช้ (โค้ดทำไว้แล้ว)
- **มีขา GPIO** ต่อปุ่มหรือไฟ LED ได้ตรงๆ (โน้ตบุ๊กไม่มี)
- **ดูเป็นงาน IoT / สิ่งประดิษฐ์จริง**

> 💡 **ยังไม่อยากซื้อ Pi?** ใช้โน้ตบุ๊กซ่อนหลังกล่องไปก่อนได้ — ต่อจอ touch เข้าโน้ตบุ๊ก เสียงไทยใช้ได้ชัวร์ (Chrome บน Windows) แค่ปุ่มกดจริงจะยังใช้ไม่ได้ ให้กดปุ่มไมค์บนจอแทน

**💡 เคล็ดลับตอนซื้อ**
- **แนะนำ Pi 4 มากกว่า Pi 5** — Pi 4 มีช่องลำโพง 3.5mm, Pi 5 ไม่มี (ต้องใช้ลำโพง USB)
- ซื้อเป็น **ชุด kit** (Pi + อะแดปเตอร์ + การ์ด + เคส + สาย HDMI) ถูกกว่าซื้อแยก
- **เช็กจอ touch ที่มี** ว่าต่อแบบไหน: HDMI + USB → ใช้สาย micro-HDMI 1 เส้น / สายแพ (DSI) → ไม่ต้อง

### 👋 ต่อแขนโบกมือ (เซอร์โว MG996R + PCA9685)

| PCA9685 | ต่อกับ |
|---|---|
| VCC | Pi ขา 1 (3.3V) — ไฟเลี้ยงชิปเท่านั้น |
| GND | Pi ขา 6 (GND) **และ** GND ของตัวแปลงไฟเซอร์โว (กราวด์ต้องต่อร่วมกัน) |
| SDA / SCL | Pi ขา 3 (SDA) / ขา 5 (SCL) |
| V+ (ขั้วสกรูสีเขียว) | **ตัวแปลงไฟ 12V→5–6V ตัวที่สอง (≥5A)** จากแบต LiFePO4 |
| ช่อง 0 / 1 / 2 | เซอร์โว หัวไหล่ / ข้อศอก / คอ (สายน้ำตาล=GND, แดง=V+, ส้ม=สัญญาณ) |

> ⚠️ **ห้ามจ่ายไฟเซอร์โวจากขา 5V ของ Pi หรือใช้ตัวแปลงไฟตัวเดียวกับ Pi** — MG996R ตอนออกแรงกินไฟตัวละ 2A กว่า ไฟตกแล้ว Pi จะรีสตาร์ทกลางคัน

- ติดตั้ง: `bash robot/web/install_autostart.sh` (เปิด I2C + ลงไลบรารีเซอร์โวให้เอง) แล้วแก้ `SIMULATOR_MODE = False` ใน `robot/config.py`
- ตรวจว่าเห็นบอร์ด: `i2cdetect -y 1` ต้องเห็น `40`
- **แขนเอียงผิดมุม / โบกแรงไป** → แก้ตัวเลข `ARM_...` ใน `robot/config.py` ที่เดียว (องศา 0–180, ความเร็ว, จำนวนครั้งที่โบก)
- ลองสั่งโบกโดยไม่ต้องแตะจอ: `curl -X POST http://localhost:5000/greet`
- ถ้าเปิดเครื่องตอนยังไม่ได้เสียบบอร์ด หุ่นยังทำงานได้ตามปกติ แค่แขนไม่ขยับ (มีคำเตือนใน log)

## 📌 สถานะ

| เฟส | สิ่งที่ทำ | สถานะ |
|-----|---------|-------|
| เว็บกล่องพูดได้ | พูด/พิมพ์ + จอใบหน้า + กันตอบมั่ว (ทดสอบบนคอม) | ✅ เสร็จ |
| ฟีเจอร์เสริม | ปุ่มคำถามยอดฮิต + แผนที่ในคำตอบ + เสียงผู้ชาย | ✅ เสร็จ |
| ซอฟต์แวร์บน Pi | ปุ่ม GPIO + รันอัตโนมัติ + kiosk เต็มจอ | ✅ เสร็จ |
| ความรู้สระบุรี | ท่องเที่ยว + OTOP + รูปสถานที่ + ระยะทางจากวิทยาลัย | ✅ เสร็จ |
| ทักทาย | แขนโบก + หน้าทักทาย + คำทัก + เปิด 2 จอบน Pi (ซอฟต์แวร์พร้อม รอประกอบแขนจริง) | ✅ ซอฟต์แวร์เสร็จ |
